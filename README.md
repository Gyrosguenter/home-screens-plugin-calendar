# Monatskalender — Home Screens Plugin

Wochenraster im Stil der iOS-Kalender-App: durchgehende Balken für mehrtägige Termine, Chips für Termine mit Uhrzeit, Kalenderwochen links, heutiger Tag rot markiert, "+N" bei Platzmangel. Die Termine kommen aus den im Hub verbundenen Kalendern (`/api/calendar`, interner Hub-Endpunkt).

Teil des Projekts [home-screens-magic-mirror](https://github.com/Gyrosguenter/home-screens-magic-mirror); als eigenes öffentliches Repo geführt, damit die Plugin-Tarball-URL ohne Authentifizierung erreichbar ist.

```bash
npm install && npm run build && npm test
```
